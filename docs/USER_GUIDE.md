# Noder User Guide (v0.9.8)

## Install

```bash
npm install
npm run electron:dev
```

## Build

```bash
npm run build:win
npm run build:mac
npm run build:linux
```

## AI Agent (Ctrl+Shift+A)

1. Paste API key (OpenRouter / Groq / NVIDIA free tiers).
2. List models → pick free or paid.
3. Auto-apply and Auto-run ON by default.
