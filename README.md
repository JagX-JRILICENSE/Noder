# Noder

**AI-first collaborative IDE** by **JagX** & **JRILICENSE** (VS Code + Qoder oriented)

Monaco editor · agent (BYOK, auto-apply, auto-run, terminal stream) · Quest board · Live Preview (web/Flutter/TS) · GitHub · themes · marketplace · one-click Push

## Quick start

```bash
npm install
npm run electron:dev
```

## Build

```bash
npm run build:win
npm run build:mac
npm run build:linux
```
